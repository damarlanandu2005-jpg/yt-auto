# ChatGPT batch prompts (10 pictures per batch, owner 29 Oct)

ChatGPT makes at most 10 pictures at a time, so the 50 prompts of PROMPTS.md (plus the Titanic pieces) are grouped
into batches. Each batch is pasted as ONE message; ChatGPT makes 10 separate pictures and one zip with exact names.
Upload each zip to GitHub: cartoon/art/inbox/ (Add file -> Upload files). A zip over 25 MB: upload the PNG files
directly instead.

## Start of every batch message (copy this first)

```
Please make 10 SEPARATE images, one image at a time (never a grid, never 2 pictures in one image).
After all 10 are done, use Python to save them as PNG files with EXACTLY the file names below and put
them all in one zip file named BATCH_NAME.zip for me to download.

STYLE for every image:
STYLE_TEXT

Images:
```

## Place style (batches 1-2)

Flat 2D vector cartoon illustration, clean thick dark-grey outlines, soft muted colours with simple flat shading,
like a modern animated explainer cartoon. Vertical 9:16 portrait, full size. Eye-level view. Empty scene: NO people,
NO animals, NO text, NO letters, NO logos. The lower third is open floor or ground with nothing on it, so characters
can stand there. Calm, tidy, not cluttered in the middle. No frame, no border.

## Object style (batches 3-6)

Flat 2D vector cartoon illustration of ONE object, clean thick dark-grey outline, soft muted colours, simple flat
shading, centred on a plain pure white background, no shadow, no text, no letters, no logos, nothing else.
Square 1:1, full size.
